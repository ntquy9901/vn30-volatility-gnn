## What is GELU?

**GELU (Gaussian Error Linear Unit):**
- Formula: `GELU(x) = x * Φ(x)` where Φ is the Gaussian CDF
- Smoother than ReLU: no sharp kink at x=0
- Probabilistic activation: weighted by Gaussian cumulative distribution
- Better gradient flow: non-zero gradients for negative inputs

**Advantages over ReLU for Volatility Forecasting:**
1. **Smoother transitions** - Better captures continuous volatility patterns
2. **Non-zero negative gradients** - Allows learning from negative deviations
3. **Probabilistic triggering** - Matches uncertainty in financial time series
4. **Dominant in 2026** - State-of-the-art for transformers and time series

```python

    H2 = F.gelu(H2)  # Smoother activation
```

## Technical Details

### GELU Formula

**PyTorch implementation:**
```python
import torch.nn.functional as F

# GELU activation
H2 = F.gelu(H2)
```

**Mathematical equivalent:**
```
GELU(x) = x * Φ(x)
where Φ(x) = 0.5 * (1 + erf(x / sqrt(2)))
```

**vs ReLU:**
```
ReLU(x) = max(0, x)
```

### Computational Cost

- **GELU:** ~10% slower per forward pass (Gaussian CDF calculation)
- **Training impact:** Negligible (~3-5% longer training time)
- **Memory:** Same as ReLU (no additional parameters)

### Numerical Stability

**GELU properties:**
- Smooth derivative everywhere (no numerical issues at x=0)
- Well-behaved gradients (no vanishing/exploding)
- Compatible with QL loss (same clamping to 1e-4)

**No additional numerical stability measures needed.**
